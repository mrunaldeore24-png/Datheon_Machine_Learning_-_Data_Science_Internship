# Task 1 – Iris Classification

### Objective
Develop supervised classification models using the Iris dataset and compare their performance.

### Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

### Models Implemented
- Logistic Regression
- Decision Tree Classifier

### Workflow
- Data Loading
- Exploratory Data Analysis (Pairplot)
- Feature Scaling using StandardScaler
- Train-Test Split (80/20)
- Model Training
- Model Evaluation
- Confusion Matrix Visualization
- Decision Boundary Visualization

### Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score

# Task 2 – California Housing Price Prediction

### Objective
Predict median house values using regression techniques and compare model performance.

### Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

### Models Implemented
- Ordinary Least Squares (Linear Regression)
- Ridge Regression (L2)
- Lasso Regression (L1)

### Workflow
- Data Loading
- Missing Value Imputation
- Correlation Heatmap
- Feature Engineering
- Categorical Feature Encoding
- Feature Scaling
- Hyperparameter Tuning using GridSearchCV
- Model Training
- Model Evaluation
- Predicted vs Actual Plot
- Residual Distribution Plot

### Evaluation Metrics
- RMSE (Root Mean Squared Error)
- MAE (Mean Absolute Error)
- R² Score
